FULL-STACK FITNESS TRACKER • JWT AUTH • RECHARTS • LIVE ON VERCEL

Live Links - Verified

Live Project GitHub Client Server

Brief Description

FitLog is a full-stack fitness tracker where users can log workouts, track calories, view progress with charts, set goals. Built for Rangpur users with JWT secure login, progress analytics, responsive dashboard, and Vercel deployment.

Challenges Faced

1. JWT auth with refresh token
2. Chart data aggregation for progress
3. CORS issue fixed on Vercel
4. Responsive Recharts on mobile
