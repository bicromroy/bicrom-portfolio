Dev-Stack

DEVELOPER RESOURCE HUB • REACT • FILTERING • MODERN UI • LIVE ON VERCEL

Main Technology Stack

Frontend: React.js, Tailwind CSS, React Router
Backend: Firebase (Auth & Hosting)
Features: Search, Category Filter, Bookmark
Deploy: Vercel (dev-stack-dq69.vercel.app)

Live Links

Live Project GitHub Client

Brief Description

Dev-Stack is a developer resource sharing platform where developers can save and share useful tools, libraries, articles. Built with React, modern filtering, search, category wise resource management. Easy UI for Bangladeshi developers to find best dev tools in one place.

Challenges Faced

1. Complex filtering logic with multiple categories
2. Firebase auth state management
3. Responsive grid layout issue
4. Search debounce performance

Future Plans

1. User login & personal collection
2. Upvote & comment system
3. AI recommendation
4. Chrome extension
5. Dark/Light theme toggle
