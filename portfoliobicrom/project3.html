RESTAURANT MANAGEMENT • MERN • ORDERING SYSTEM • LIVE ON VERCEL

Deploy: Vercel (fokira-cafe.vercel.app)

Live Links

Live Project GitHub Client

Brief Description

My Fokira Cafeteria is a full cafeteria management system for Rangpur/Dinajpur local restaurants. Customers can view menu, add to cart, place order, track order. Admin can manage menu, orders, users. Built to digitalize local cafe business in Bangladesh with MERN Stack.

Challenges Faced

1. Cart state with localStorage sync
2. Order management real-time
3. Image upload for menu items
4. Role based admin/user auth

Future Plans

1. Online payment bKash/Nagad
2. Real-time order tracking
3. Table booking system
4. Sales report & analytics
5. Mobile app for waiter
